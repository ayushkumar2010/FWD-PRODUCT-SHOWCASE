# 🎓 QuizWiz - Dynamic Quiz Application

This project is a web-based interactive quiz platform designed to provide an engaging 
learning experience through category-based quizzes, multiple difficulty levels, and 
instant feedback mechanisms.

---

## 🌐 Live Demo
👉 (https://ayushkumar2010.github.io/FWD-PRODUCT-SHOWCASE/)

---

## ✨ Features
- 🧠 Multiple Subjects – Choose between Mathematics, Science, History, Web Development, Technology & General Knowledge.

- ⚙️ 3 Difficulty Levels – Easy, Medium & Hard, each with 4 questions.

- ⏰ Timer Functionality – 10-second countdown for each question.

- 💬 Instant Feedback – Explanations shown after each question submission or on timeout.

- 🧾 Leaderboard System – Stores and displays top scores using LocalStorage.

- 🙋 User Login Panel – Username is saved for personalization.

- 💡 Responsive Design – Accessible on mobiles, tablets, and desktops with a clean gradient UI.

---

## 🛠️ Tech Stack
- Frontend:
  - HTML5 — Structural layout of all components
  - CSS3 — Custom styling, gradients, shadows, and animations
  - JavaScript — Dynamic quiz logic, timer, validation, and leaderboard handling

- Storage:
  - LocalStorage — For saving usernames and score histories

- Deployment:
  - GitHub Pages

- Version Control:
  - Git & GitHub

---

## 🧩 System Overview
- Login Panel:
  - Enter your username to begin.
  - Uses LocalStorage for session memory.

- Quiz Setup:
  - Select subject and difficulty.
  - Begin quiz with the Start button.

- Quiz Engine:
  - Displays one question at a time with a 15-second timer.
  - Marks answers instantly and shows explanations.

- Result Screen:
  - Displays score summary, encouraging messages, and image feedback.

- Leaderboard:
  - Filters by subject and difficulty.
  - Displays previous attempts with username, score, date, and time.
